Flask>=3.0
requests>=2.31
feedparser>=6.0.11
lxml>=5.0
readability-lxml>=0.8.1

# 正文提取的二级兜底：readability 提得太短时才上场（见 feed_parser.extract_from_html）。
# 只用它的 extract() 函数，页面是我们自己抓好传进去的 —— 它的 fetch_url 一律不用，
# 否则会绕过我们自己的 timeout / 代理 / UA / Cookie。
# 注意：它会一并装上 courlan / htmldate / dateparser / justext / tld 等若干依赖，
# 并把 lxml 升到 6.x（实测不影响 readability / feedparser）。
trafilatura>=2.0

# 让 Python 使用操作系统自带的证书库（Windows 证书存储），而不是只认 certifi。
# 有些网络环境下（例如装了 SteamTools 这类会做 HTTPS 中间人的工具）GitHub 的证书
# 会被替换成工具自己的自签证书，此时只有系统证书库认得，Python 默认会报
# SSLCertVerificationError → 表现为"GitHub 每日趋势抓取失败"。
truststore>=0.9
